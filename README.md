# Health Monitoring & Triage Platform

An intelligent, early health monitoring and decision-support system designed to track symptoms over time, evaluate risk levels using a database-driven explainable rules engine, log medicines, and generate AI health summaries for doctor visit preparation.

## Project Structure
- `/backend`: Node.js, Express, Sequelize, PostgreSQL, and Gemini API.
- `/frontend`: React, Vite, Tailwind CSS, Axios, and Chart.js/Recharts.

## Getting Started
1. Set this directory (`C:\Users\omkar\.gemini\antigravity\scratch\health-triage-platform`) as your active workspace.
2. Initialize backend and frontend applications as outlined in `task.md`.
